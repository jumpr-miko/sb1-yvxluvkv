Summary

Salesforce implementation progress was reviewed to establish standardized workflows, security protocols, and phased project timelines.

Salesforce Architecture and Workflow
The system will utilize a tab-based console to centralize records, automating workflows by linking deals, contacts, and accounts. Guided screen flows will replace manual status updates to ensure process adherence.

Security and Data Governance

Decisions

Aligned

  • File storage migration to GCP The team decided to replace Dropbox with Google Cloud Platform (GCP) for file storage to enable structured access.
  • Screen flow usage for workflows The team decided to utilize screen flows to enforce data validation and guide the signup process, ensuring required fields are completed before allowing status transitions.

  • Sales rep data access restriction The system will be configured with private access and sharing rules so that sales reps can only view their own assigned records, preventing unauthorized visibility of other reps' work.
  • Deal rep assignment tracking structure The team decided to use a related child object to track deal rep assignment history rather than creating multiple rows within the primary deal object.
  • Phase 1 scope adjustment The team decided to include 'deal rep assignment' automation in Phase 1, moving it up from its originally planned release phase.
  • Internal user testing requirement The core team will perform the initial evaluation and testing of the Salesforce UI and workflows before rolling access out to the broader sales rep team.
  • Sprint-based delivery model The team decided to adopt a sprint-based delivery model for features following the completion of Phase 1, replacing the originally planned massive, rigid phase structure.
  • Decommissioning of legacy systems The team decided to decommission Dropbox and Airtable once their respective functionalities are fully migrated and verified in Salesforce.
  • Super-user based training approach The team decided to implement a 'super-user' training model, where a small group of internal users is trained first to lead the rollout, including a planned in-person launch day.
  • Research phase completion timeline The research phase completion date is set for mid-August.
