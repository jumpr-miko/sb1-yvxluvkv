Decisions
Aligned
* Operator and partner ID system implementation The team will adopt a unique ID system for operators and partners for API mapping, supported by a shared import sheet to ensure data consistency between the CMS and Salesforce.
* Market and country ID system implementation The team will implement an ID system for market, country, and state fields in the API to improve integration reliability and avoid data mapping errors.
* Retention of rep slug identifiers The team will continue using existing rep slugs as unique identifiers for now rather than creating a new rep ID system.
* Deal makeup data transfer strategy The team will include the deal makeup—specifically the operator, partner, market, and vertical—in all study click links.
* Click record deduplication removal policy Server-side deduplication of click records is removed to ensure all individual click events are tracked and captured in Salesforce.
* Salesforce click ID storage standard The system will store the Salesforce unique ID for each click record in the local database to enable two-way troubleshooting.
