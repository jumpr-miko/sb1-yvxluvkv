Decisions
ALIGNED
* Standard Salesforce objects prioritized Standard Salesforce objects are prioritized over custom objects for the new implementation, defaulting to native features whenever possible.
* Partners and Operators as Accounts Partners and Operators are to be implemented as standard Salesforce Account objects to enable effective contact relationship tracking.
* Opportunity object excluded for Deals The Salesforce Opportunity object is excluded for tracking Deals to prevent incorrect forecasting and ensure accurate record representation.
* Lead object constraint removed The requirement to use the Lead object for signups is removed, allowing the consulting team to select the most appropriate object type for the business model.
* External file linking strategy adopted The file storage strategy will prioritize saving links to external files (e.g., Dropbox, Drive) instead of uploading raw files to Salesforce to optimize storage costs.
